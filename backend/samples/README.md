Optional test images the app shows under "Or try a test image from the dataset".

- `images/` → SAR images (e.g. `img_0012.jpg`)
- `labels/` → their colour masks with the same name (e.g. `img_0012.png`)

The Kaggle notebook copies a few test images into `export/samples/`, so you can paste them here.
When a label exists, the app also shows the ground truth and the IoU for that image.
